When an interrupt occurs, the CPU core stops its current task and runs a kernel routine. The system saves the current context of the running process so it can be restored later, effectively suspending and then resuming the process. This context is stored in the Process Control Block (PCB) and includes CPU register values, process state, and

memory-management information. In general, a state save of the CPU is performed, whether it is in user mode or kernel mode, followed by a state restore to continue execution.

Switching the CPU to another process requires saving the current process state and restoring the state of another process. This operation is called a context switch. During a context switch, the kernel saves the context of the old process in its PCB and loads the saved context of the new process. Context-switch time is considered pure overhead
