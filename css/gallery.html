A process terminates when it completes its execution and requests the operating system to delete it using the exit() system call. At the time of termination, the process may return a status value (usually an integer) to its parent process using the wait() system call. Once the process ends, all its resources such as memory, open files, and I/O buffers are released by the operating system.
